Built for speed. Designed for zero maintenance.

Stateless and private

No storage, no database lookups, and no tracking. Each request executes and is immediately forgotten.

Zero API keys to manage

No sign-up form, no OAuth handshake, and no keys to rotate. Call it directly from CI, scripts, or apps.

Edge-cached performance

Repeated requests are served directly from Cloudflare’s global network with single-digit millisecond latency.

Drop it into any codebase

curl -X POST "https://service.w-b.dev/api/action" \ -H "Accept: application/json"

Fair Use & Rate Limits

Each client IP is allocated 60 requests per minute. Beyond that, the service responds with HTTP 429 Too Many Requests and a Retry-After header.

Edge-cached requests bypass origin rate limiting.
